# IQC 影像辨識 V1.0

由正式 DS 工作台「更多 → IQC 影像辨識」進入，沿用工作台登入。

- `System_Access_Master.iqc_image_enabled` 獨立控制入口、主檔讀取、正式寫入及收據查詢。預設不授權任何帳號，ADMIN 也需勾選。
- 本版沿用 RC31.19 已驗收的本機 OCR、批次、人工歸類、去重、照片清理及送出流程。照片不隨建檔送往後端；Cloud 輔助尚未啟用。
- 正式批次、本機資料庫及收據與 RC 分開；各登入帳號分開保存。既有 RC 草稿與測試收據不自動轉正式。
- 人工核對後寫入既有正式 IQC_Log；日期、操作者由後端決定。相同送出識別碼可查收據及重試，收到完整收據才列入歷史。
- 三個後端沿用既有 Google 專案：登入及 Portal 增加獨立權限回覆；日報專案新增影像專用部署，既有日報、Dashboard 與 RC 部署保持原版本。

驗收：管理者自行勾選一位人員權限，該人員重新登入後應看到入口。以尚未正式建檔的 CTN 建立一批，核對預覽後送出；應取得正式 IQC 收據並進入歷史。未勾權限帳號不應看到入口。

CG 的合成測試不會在正式表建立測試鋼瓶；首次真實入帳仍需由獲授權的操作者完成。
