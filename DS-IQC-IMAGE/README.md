# IQC 影像辨識 V1.1

由正式 DS 工作台「更多 → IQC 影像辨識」進入，沿用工作台登入。

- `System_Access_Master.iqc_image_enabled` 獨立控制入口、主檔讀取、正式寫入及收據查詢。預設不授權任何帳號，ADMIN 也需勾選。
- 本版移入使用者已驗收的 RC31.25：RT 標頭辨識與歸屬修正、頁內原照片查看與縮放拖移、CTN 依照片順序編號、先排滿左欄再排右欄、需核對字元黃底提示，以及每組共用的多選移除與復原。照片不隨建檔送往後端；Cloud 輔助尚未啟用。
- 正式批次、本機資料庫及收據與 RC 分開；各登入帳號分開保存。既有 RC 草稿與測試收據不自動轉正式。
- 人工核對後寫入既有正式 IQC_Log；日期、操作者由後端決定。相同送出識別碼可查收據及重試，收到完整收據才列入歷史。
- V1.1 保留 V1.0 的正式端點、帳號儲存鍵、資料結構及權限；既有正式批次、照片、人工更正與收據可繼續使用。本次不更新 Google 後端、不變更人員權限。

檢查：81 項正式模型測試及 24 項正式工作台瀏覽器合成檢查通過，涵蓋舊資料保留、RT、CTN 編輯與移除、照片查看、送出遺失回應後查收據、帳號隔離及權限撤銷。線上後端健康正常；主檔、送出、收據三個路由均拒絕未登入請求。

正式入口確認：重新載入工作台，由有既有權限的人員開啟影像辨識，應顯示 V1.1，原批次及歷史仍在。下次正常作業核對照片與 CTN 後送出，應取得正式 IQC 收據並進入歷史。已通過的 RC31.25 功能不需整套重驗；未勾權限帳號仍不應看到入口。

CG 的合成測試不會在正式表建立測試鋼瓶；本次尚未代替操作者進行 iPhone 正式入帳實測。
