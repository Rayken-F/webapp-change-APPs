# DS Grinding Recovery RC v10 — 2026-08-23

## Scope
RC only. Production `ds-app/` and formal IQC writes remain untouched.

## Fixes
- Shell viewport isolation: home/login stabilization no longer writes `--ds-shell-vh`; module-mode geometry is owned only by RC v3.
- LINE-style bottom navigation moved slightly lower while retaining iPhone home-indicator clearance.
- OCR Worker initialization watchdog: 45s timeout, maximum 2 attempts, visible elapsed-time status.
- Timed-out Worker is terminated if it later resolves.
- OCR transaction guard treats initialization/recognition failure as terminal, unlocks the batch, labels stuck `辨識中` rows as `待重試`, and allows direct retry without deleting/reselecting photos.
- During OCR, duplicate recognize/delete/reselect actions are blocked and the front end shows elapsed local OCR time.
