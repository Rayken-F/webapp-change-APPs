1. Bottom DS module navigation uses a LINE-like floating capsule layout in RC only.
2. IQC Honeywell OCR worker initialization retries up to 3 times to reduce first-run weak-network/cache failures.
3. Multipass OCR is conservative: the primary pass owns RT segmentation; supplemental passes may only fill missing CTNs and cannot exceed the label total.
4. IQC image grouping key is `RT + cylinder status + plant/area`.
5. The same grouping key across multiple photos is merged and CTNs are deduplicated.
6. Batch-wide region/status fields are hidden in IQC Image RC; status and plant/area are recognized/reviewed per group.
7. Formal IQC write remains locked by the existing RC safety guard.
