# RC v12 — 2026-08-23

Status: TESTING ONLY. Do not promote to production before field PASS.

## P0 module navigation / bottom bar

Root cause found in RC v11: the full-screen rule `#appShell.module-mode .module-frame { display:block!important }` had higher CSS specificity than the production `.module-frame.hidden { display:none!important }`. Multiple prewarmed iframes could therefore remain visually stacked; rapid navigation exposed the top iframe (often Dashboard) even when Daily Report or Grinding was selected.

v12 fixes:
- explicit `#appShell.module-mode .module-frame.hidden { display:none!important }`
- inactive frames also receive hidden visibility, pointer-events none and negative z-index
- new `rc-nav-visibility-guard-v12.js` applies last-click-wins enforcement after rapid navigation bursts
- module iframe geometry remains full viewport; bottom navigation remains overlay and does not reserve module height

Rollback: restore `rc-shell-stability-v9.css` blob from RC v11 and remove `rc-nav-visibility-guard-v12.js` from the RC index.

## P0 IQC multi-photo OCR stability / recall

Field result from v11: fixed three-photo set improved from ~1/5 batch success to ~3/5, but RT 113374 regressed from about 15 recognized CTNs in v10 to 5 in v11.

Root cause: v11 preserved per-photo Worker isolation for memory safety but reduced the recognition ensemble too aggressively.

v12 keeps per-photo Worker lifecycle but restores robust multi-pass recognition inside each photo:
1. primary PSM 6
2. sparse-text PSM 11 when confidence/coverage is insufficient
3. cropped high-contrast PSM 6 if a count gap remains
4. conservative merge by RT/status/plant with expected-count cap and duplicate ownership protection
5. Worker terminate after each photo plus a short WebKit cleanup yield

Acceptance requested by field owner:
- fixed 3-photo set: 10 rounds, at least 8 fully successful rounds
- any 5-round sample should normally be >=4/5
- no regression to split duplicate RT/status/plant groups
- RT 113374 recognition should not regress to the v11 5/19 level

Rollback: restore `iqc-ocr-multipass-hook-rc-v3.js` from RC v11.
