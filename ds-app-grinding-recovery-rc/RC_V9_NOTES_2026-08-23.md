# DS Grinding Recovery RC v9 — 2026-08-23

Status: RC only / NOT Production.

## Changes
- Stabilize iOS PWA viewport during re-login and initial home loading so the page does not temporarily shrink and expose a black bottom gap.
- Move LINE-style floating bottom navigation closer to the physical screen bottom while preserving safe-area handling.
- Add IQC OCR transaction guard:
  - photo add/compress/IndexedDB write must settle before recognition can start;
  - one recognition task per batch at a time;
  - duplicate recognition clicks are cancelled with a visible warning;
  - delete/reselect/new-batch actions are blocked while recognition is running;
  - photo mutation gets a settle window before a new recognition run;
  - 12-second ingest watchdog prevents an indefinite lock.
- Existing RC v8 grouping remains: RT + cylinder status + plant/area, with conservative multipass CTN supplementation.

## Why
Observed on iPhone RC v8:
1. re-login and initial announcement-board load temporarily used a shorter viewport, leaving a black gap until production requirements completed loading;
2. bottom navigation sat slightly too high;
3. deleting/reselecting photos then immediately re-running OCR could race asynchronous image compression/IndexedDB writes and the previous recognition lifecycle, producing an empty/invalid recognition state.

## Rollback
Remove `rc-shell-stability-v9.css`, `rc-shell-stability-v9.js`, and `iqc-ocr-transaction-guard-v9.js` from the RC index and restore the RC v8 index. Production DS App is not modified by this RC.
